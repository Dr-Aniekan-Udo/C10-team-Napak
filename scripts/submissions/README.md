# Submissions

Upload-format Experiment 1 ranking artifacts live here. `submission-1.csv`
through `submission-5-cross-encoder.csv` are retained as immutable upload-format
artifacts; each contains five unique document IDs for each test query.

`submission-5-cross-encoder.csv` is recorded as the highest-scoring submitted
artifact. Submission status details are deferred to the research ledger
(`docs/research/retrieval-methods.md`).

Experiment 2 is intentionally omitted from the initial public package until two
additional tests pass; no completion claim is made here.
